# ЛР1. Середовище, подання зображень, колірні простори

Дисципліна «Системи комп'ютерного зору (частина 1)», спеціальність 113 «Прикладна математика», 7-й семестр.
Автор: <ПІБ, група>.

## Мета
Налаштувати робоче середовище; дослідити цифрове подання зображень (типи даних, порядок каналів, переповнення `uint8`, втрати при стисненні, EXIF); кількісно порівняти стабільність порогового виділення об'єкта в RGB і HSV при зміні освітлення; дослідити аліасинг, інтерполяцію та гамма-кодування; зібрати власний набір із 20 зображень для ЛР3 і ЛР4.

## Вимоги
- Python 3.10 або новіший
- Бібліотеки: `opencv-contrib-python`, `numpy`, `matplotlib`, `scipy`, `Pillow` (точні версії – у `requirements.txt`)
- Випадковий стан зафіксовано: `np.random.seed(42)` на початку `src/lab01.py`

## Структура
```
lab01/
├── README.md
├── requirements.txt     зафіксовані версії залежностей
├── .gitignore           виключає *.jpg, *.png, *.mp4, .venv/, __pycache__/
├── src/lab01.py         увесь код (частини A, B, C)
├── data/                вхідні дані (у git не потрапляють, див. нижче)
│   └── dataset/         власний набір із 20 кадрів
├── results/             числові результати (output.txt)
├── figures/             рисунки для звіту
└── report/              звіт у PDF
```

## Вхідні дані
Зображення в репозиторій не додаються (правило курсу: у git лише код і невеликі результати). Покладіть файли в `data/` самостійно: <посилання на диск/архів з даними>.

| Файл | Призначення |
|---|---|
| `photo.jpg` | деталізований кадр (частини A, C) |
| `texture.jpg` | дрібна регулярна текстура (аліасинг, крок 12) |
| `object_light1.jpg`, `object_light2.jpg` | один кольоровий об'єкт за двох освітлень (денне світло / лампа розжарювання) |
| `object_mask1.png`, `object_mask2.png` | еталонні маски: об'єкт білий, фон чорний (зроблено вручну в графічному редакторі) |
| `dataset/*.jpg` | 20 кадрів однієї текстурованої сцени: 10 ракурсів повороту камери з однієї точки (перекриття ≈ 40 %), 5 відстаней, 5 освітлень |

## Запуск
```
python -m venv .venv
.venv\Scripts\activate          # Windows;  Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cd src
python lab01.py
```
Перевірити встановлення: `python -c "import cv2; print(cv2.__version__)"`.

## Що вийде
- `results/*.csv` – числові результати у таблицях: `a_properties`, `a_overflow`, `a_compression`, `a_exif`, `b_thresholds`, `c_aliasing`, `c_interpolation`, `c_gamma_average`
- `results/output.txt` – копія всього виводу в консоль, зокрема:
  - властивості масиву; частка пікселів із переповненням `uint8`;
  - таблиця «формат – якість – розмір – PSNR» для PNG і JPEG (95, 75, 50, 25, 10);
  - EXIF власних знімків і кількість кадрів набору;
  - межі порогів, IoU та accuracy для RGB, HSV, HSV (H, S) на двох кадрах; accuracy порожньої маски;
  - PSNR методів зменшення ×4; PSNR ± розкид для 4 методів інтерполяції ×8;
  - порівняння усереднення гамма-кодованих значень і освітленостей.
- `figures/`:
  - `a_bgr_rgb.png` – порядок каналів;
  - `a_overflow.png` – переповнення `uint8`;
  - `a_psnr_size.png` – залежність PSNR від розміру файлу JPEG;
  - `b_masks.png` – карти помилок сегментації;
  - `c_aliasing.png` – аліасинг при зменшенні;
  - `c_interpolation.png` – методи інтерполяції;
  - `c_gamma.png` – гамма-корекція та передавальні характеристики.

## Звіт
`report/` містить звіт 3–5 сторінок за структурою: мета, вихідні дані, теоретичні відомості, хід роботи, результати, аналіз, висновки (3–5 пунктів, кожен із числом), декларація про використання генеративного ШІ.

## Використання генеративного ШІ
Claude (Anthropic) використовувався для консультацій щодо методики та допомоги в написанні коду; результати отримано запуском коду на власних даних, відповідальність за код і висновки несе автор.

# ЛР2. Калібрування камери та усунення дисторсії

Дисципліна «Системи комп'ютерного зору (частина 1)», спеціальність 113 «Прикладна математика», 7-й семестр.
Автор: <ПІБ, група>.

## Мета
Оцінити внутрішні параметри камери (матрицю K) і коефіцієнти дисторсії за знімками шахівниці (метод Чжана); навчитися оцінювати якість калібрування (похибка репроєкції по кадрах, викиди, залежність від кількості кадрів); усунути дисторсію і зберегти параметри для ЛР5.

## Вимоги
- Python 3.10+, `opencv-contrib-python`, `numpy`, `matplotlib`, `Pillow` (точні версії – у `requirements.txt`)
- Випадковий стан зафіксовано: `np.random.seed(42)` і `default_rng(42)` у `src/lab02.py`

## Структура
```
lab02/
├── README.md
├── requirements.txt
├── .gitignore
├── src/lab02.py          увесь код (з поясненнями в коментарях)
├── data/
│   ├── calib/            калібрувальні кадри calib01.jpg ... calib25.jpg (у git не потрапляють)
│   └── line_test.jpg     кадр із прямою лінією біля краю (крок 14)
├── results/              числові результати (CSV) і camera_params.yml
├── figures/              рисунки для звіту
└── report/               звіт у PDF
```

## Вхідні дані
Фото в репозиторій не додаються, посилання: <посилання на диск/архів>.
- Шахівниця 9×6 внутрішніх кутів (10×7 клітин) на жорсткій основі, розмір клітини виміряно лінійкою: <значення> мм.
- 25 кадрів `calib01…calib25.jpg`: 5 фронтальних з різних відстаней, 10 під нахилом 20–45°, 10 із шаблоном у різних частинах кадру (зокрема в кутах).
